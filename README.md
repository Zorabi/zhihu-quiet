# 知乎静阅

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](LICENSE)

知乎静阅是一个为桌面版知乎提供响应式居中布局和柔和阅读配色的用户脚本。

## 功能

- 正文随窗口宽度调整，首页、问题页、回答详情页、搜索和专栏使用集中阅读布局。
- 提供「跟随系统」「知乎默认」「石墨灰」三种配色；跟随系统会自动切换浅色与深色，知乎默认不注入自定义主题色，石墨灰始终使用柔和暗色。跟随系统的浅色也是脚本配色，并非知乎原始主题。
- 固定启用头像置左、隐藏侧栏，滚动后自动显示返回顶部入口。
- 正文展开后提供靠近内容列的悬浮收起入口；评论展开时优先收起评论。
- 直答关键词保留文字、取消跳转；普通正文链接保留。
- 可设置顶栏精简、隐藏创作卡片、搜索推荐净化、低评论内容过滤等阅读偏好。

右侧工具条提供「阅读偏好」和「返回顶部」。不包含自定义背景图片功能。

## 安装

1. 在桌面浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击[安装知乎静阅](https://raw.githubusercontent.com/Zorabi/zhihu-quiet/main/zhihu-quiet.user.js)，在脚本管理器中确认安装。
3. 打开或刷新 [知乎](https://www.zhihu.com/)。

安装了其他知乎美化、简化脚本时，建议先停用，避免样式和按钮重复。由本项目早期个人版本迁移时，可在原脚本编辑器中全选替换，以保留该脚本已有的偏好存储。

脚本提供 GitHub 更新地址，后续更新由脚本管理器按其自身设置检查。

## 使用

「知乎默认」仅表示沿用网站的主题色，仍保留居中布局、净化和你开启的分隔线等功能；要查看完全原始的网站外观，请暂停「启用静阅」。

- 点击右侧工具条的偏好图标，切换配色或调整内容过滤。
- 页面滚动超过 300px 后，工具条显示返回顶部。
- 暂停「启用静阅」可恢复网站原有外观；按 Escape 可关闭偏好面板。
- 头像位置和侧栏布局采用固定设置，不提供单独开关。

## 兼容性与限制

适配范围为 `www.zhihu.com` 和 `zhuanlan.zhihu.com` 的桌面网页。主要适配目标为 Chrome 与 Tampermonkey，不承诺移动版及所有浏览器表现一致。

知乎改版或其他浏览器扩展注入样式后，部分布局可能需要更新。发布前已完成 JavaScript 语法检查，以及基于离线页面的布局、偏好迁移和悬浮按钮交互检查；离线检查不能替代每个在线页面的验证。

## 开发与反馈

无需构建工具，直接编辑 `zhihu-quiet.user.js`。安装 Node.js 后可执行语法检查：

```bash
node --check zhihu-quiet.user.js
```

提交问题时，请附页面类型、窗口宽度、脚本版本和已遮盖个人信息的截图。提供 HTML 时请先移除账户信息、令牌及其他隐私数据。欢迎通过 Issue 或 Pull Request 反馈。
